# World Chronicle 국기 이미지

2026년 시나리오의 국가는 기존 국가 코드로 96×72픽셀 국기를 찾는다. 지역별 국기 246개를 한 장의 무손실 WebP에 담았다. 원본 자료에 있는 국가 ID, 지도와 저장 데이터에는 이미지를 추가하지 않는다. 시나리오가 직접 지정한 국기는 모든 시대에서 우선한다. 1440년과 1936년에는 시나리오의 국기 또는 국가 문장을 표시한다.

대부분의 그림은 Panayiotis Lipiridis의 **flag-icons 7.6.0**에 포함된 4대3 SVG에서 변환했다. 배포 파일 안에 MIT 허가문 전문을 포함한다. [원본의 고정 버전](https://github.com/lipis/flag-icons/tree/6d6982dc20b2eb50967a343f05b60fbb81014e5f/flags/4x3) · [MIT 허가문](./flag-icons.txt)

북키프로스와 소말릴란드의 그림은 Wikimedia Commons에서 공개한 퍼블릭 도메인 SVG를 사용했다. 북키프로스 파일의 SHA-1은 `0f69a4c99c7b850ac7466227944005d2560bef43`, 소말릴란드 파일의 SHA-1은 `d829c7b74546d980ded266b2ae4e0e544667e3a7`이다. [북키프로스 원본과 이용 조건](https://commons.wikimedia.org/wiki/File:Flag_of_the_Turkish_Republic_of_Northern_Cyprus.svg) · [소말릴란드 정부 원본과 이용 조건](https://commons.wikimedia.org/wiki/File:Flag_of_Somaliland.svg)

현대 지도와 같은 Natural Earth 5.1.2의 `ADM0_A3`와 `ISO_A2_EH`를 연결했고 클리퍼턴섬은 컬렉션의 `cp` 그림을 사용했다. 호주 외부 영토 세 항목은 호주 국기, 아크로티리와 데켈리아는 영국 국기를 사용한다. [지도 코드 원자료](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_10m_admin_0_countries_lakes.geojson) · [호주 정부의 지역 상징 설명](https://www.pmc.gov.au/resources/australian-symbols-booklet/state-and-territory-symbols/symbols-other-territories-australia) · [영국 정부의 해외 영토 자료](https://assets.publishing.service.gov.uk/media/5a78ab88e5274a277e68e8a9/ot-wp-0612.pdf)

무주지와 국기 대응을 확정하기 어려운 시설·완충 지대·분쟁 지역에는 기존 문장을 표시한다. 해당 지도 코드는 `NEU`, `BJN`, `BRI`, `BRT`, `CNM`, `KAB`, `KAS`, `PGA`, `SCR`, `SER`, `SPI`, `USG`다. 국기는 게임 내 지역을 구분하는 표식이다.
